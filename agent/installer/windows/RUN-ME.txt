CSPC-ICTU SERVER MONITORING AGENT  —  Windows
=============================================

Copy this WHOLE folder to the Windows computer you want to monitor.

  cspc-agent-windows-amd64.exe   the agent (nothing else to install)
  install.ps1                  installs it to run at every boot
  RUN-ME.txt                   this file

It reports CPU, memory, uptime, process count and EVERY fixed drive (C:, D:, ...)
every 10 seconds, plus its own details (IP, RAM, disk size) hourly. If the backend
goes down it holds about 40 minutes of readings and fills them in afterwards, so an
outage leaves a gap in the live view but not in the stored history.

-----------------------------------------------------------------------
BEFORE YOU START
-----------------------------------------------------------------------
  1) The backend PC must be ON and on the SAME network as this computer.
     Open  http://192.168.100.9:3000  in this computer's browser.
     You should see:  {"error":"Route not found"}
     If it does not load -> wrong network, or the firewall on the backend PC is
     blocking port 3000. Fix that before continuing.

  2) Get an install key from an admin. On the dashboard:
       Server Metrics -> Agent install keys -> + New key
     It starts with AIK- and the dashboard shows the ready-made command.

  3) DOWNLOADED this folder (Google Drive, email, browser) instead of copying it
     from a USB stick? Windows blocks downloaded programs. Run this once in the
     PowerShell window you open below:
       Get-ChildItem -Recurse | Unblock-File
     The agent is also unsigned, so SmartScreen may say "Windows protected your
     PC" -> "More info" -> "Run anyway" (and allow it in antivirus if flagged).

-----------------------------------------------------------------------
INSTALL
-----------------------------------------------------------------------
  1) Right-click PowerShell -> "Run as administrator", then cd into this folder.

  2) If you get an execution-policy error, run this once:
       Set-ExecutionPolicy -Scope Process Bypass

  3) Install. Put the key in a VARIABLE first, so it does not sit in the process
     list or in PowerShell's saved history:
       $env:CSPC_INSTALL_KEY = '<INSTALL_KEY>'
       .\install.ps1 -ApiUrl "http://192.168.100.9:3000"
       Remove-Item Env:\CSPC_INSTALL_KEY
     Passing the key as a parameter still works if you prefer:
       .\install.ps1 -ApiUrl "http://192.168.100.9:3000" -InstallKey "<INSTALL_KEY>"
     It installs to C:\Program Files\CSPC Monitoring Agent, registers, and waits.

  4) An ADMIN approves it on the dashboard:
       Server Metrics -> Pending agent approvals -> Approve this PC

  5) Done. The PC appears Online within about 10 seconds and starts again at every
     boot — including while the building is running on UPS/battery power.

  Check it worked:
     Dashboard  -> this PC is Online, with CPU/memory figures and a Volumes list.
     This PC    -> Get-ScheduledTask -TaskName "CSPC-ICTU Monitoring Agent"

-----------------------------------------------------------------------
UPGRADING AN AGENT THAT IS ALREADY INSTALLED
-----------------------------------------------------------------------
  Do NOT re-register — the PC keeps its enrolment and approval, you are only
  swapping the program file. Stop it first (Windows locks a running .exe):

       Stop-Process -Name cspc-agent -Force
       $env:CSPC_INSTALL_KEY = '<INSTALL_KEY>'
       .\install.ps1 -ApiUrl "http://192.168.100.9:3000"
       Remove-Item Env:\CSPC_INSTALL_KEY

  It warns that the key was not used — that is expected, and nothing needs
  approving again. To move this PC onto a DIFFERENT install key (only if an admin
  asks), add  -ReEnroll  to that command: it keeps its identity and history.

  Installed before August 2026, when the agent was called go-agent? Just run the
  command above. The installer finds the old copy, carries this PC's enrolment
  across and removes it — nothing extra to do, and nothing needs approving again.

-----------------------------------------------------------------------
TROUBLESHOOTING
-----------------------------------------------------------------------
  "Invalid install key"           -> the key was revoked, expired or mistyped.
                                     Ask an admin for a new one.
  "registration was rejected or removed by an administrator", straight after
   step 3                         -> this program file is older than the backend.
                                     Ask for the current folder.
  "send attempt 1/3 failed"       -> backend not running, wrong address, or
                                     firewall. Re-do "Before you start" step 1.
  PC never appears                -> nobody approved it (step 4), and the
                                     approver must be an admin.
  PC shows "Maintenance"          -> an admin parked it on purpose; it keeps
                                     recording but raises no alerts. "Resume" on
                                     the Server Metrics page brings it back.
  Agent stopped and agent.conf is
   gone                           -> an admin removed this server, or revoked the
                                     key it enrolled with. It needs a current key
                                     and a fresh approval to come back.
  Stops reporting on battery, or
   after a reboot                 -> an OLD install. Re-run step 3; this build
                                     keeps running on UPS power.

KEEP THIS FOLDER PRIVATE — the install key is a shared secret. On Google Drive
share it to named people, never "anyone with the link". Never share an agent.conf
file: it holds that machine's own device token.

Do not paste an install key into a chat, a ticket or a shared document. If one gets
out, an admin revokes it on the dashboard (Server Metrics -> Agent install keys) and
issues a new one — revoking a key does NOT stop the PCs it already enrolled.
